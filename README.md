# Israel Map Practice

Hebrew drag-and-drop geography practice with 19 labels.

Open `index.html` in a browser. No build step or dependencies are needed.

- Place and move words freely.
- Select בדוק to check answers.
- Select הצג פתרון to see correct locations; missed answers appear orange.
- Return to practice without losing placements.
- Start a new round to shuffle the word bank.

Geographic data and outlines are derived from Natural Earth (public domain).
